# Промпт для Claude Code — второй раунд правок главной страницы

Работай в ветке **`fix/web-homepage-polish`** (там уже реализован первый
раунд правок — коммиты `cd98910`…`750bc82`), не поверх `feature/web-homepage`
и не с нуля. Прочитай
`docs/tz/web-homepage-fixes-round2/TZ-web-homepage-fixes-round2.md` — там
разобран конкретно код из этой ветки (не исходная версия), с привязкой к
файлам и строкам.

Коротко, 5 пунктов:

1. **Небо Nightreign сделать всегда видимым фоном**, убрать
   пасхалку-триггер (7 кликов по логотипу) — автор её не нашёл. Логотип
   снова обычная ссылка на "/".
2. **Земля должна быть статичной**, реагировать только на курсор — убрать
   постоянное автовращение (`ROTATION_SPEED` в `animate()`), которое
   раньше шло параллельно с курсорным наклоном. На тач-устройствах — без
   какого-либо движения (не заменять на автономный дрейф — в этом дизайне
   его не должно быть, в отличие от похожего паттерна на a-kulebyakin.ru).
3. **Шрифт значений в карточках статистики** — `.stats-row-value` с
   `--font-heading` (Unbounded) на `--font-mono` (JetBrains Mono): на
   мелком кегле дисплейный шрифт визуально не отличим от системного, вся
   строка карточки должна читаться одним "телеметрическим" стилем.
4. **Модалки, кроме APOD, увеличить** — не шириной (она уже одинаковая для
   всех четырёх), а минимальной высотой + центрированием короткого
   содержимого по вертикали.
5. **Стилизовать скроллбар** под тёмную стеклянную тему сайта (страница +
   `.detail-modal`).

Все технические детали (что именно менять, почему, в каком файле) — в самой
ТЗ, не пересказываю здесь повторно.

## Процесс

Продолжение той же ветки — не обязательно новая ветка на этот раунд,
можно так же, как в первом раунде (несколько коммитов по смыслу внутри
`fix/web-homepage-polish`). Обязательный прогон `ruff`/`mypy`/`pytest`
перед тем, как считать раунд завершённым.
