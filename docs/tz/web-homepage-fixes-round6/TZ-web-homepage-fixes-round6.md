# TZ-web-homepage-fixes-round6.md — шестой раунд доработки главной страницы

## Контекст

Round 5 (`docs/tz/web-homepage-fixes-round5/`) — фиксированный поворот
Земли на Азию — ещё не влит (PR round 4 (#23) смёржили раньше, чем был
запушен коммит round 5, поэтому round 5 пришлось переносить на новую
ветку от актуального `main`; этот раунд идёт следом на той же ветке, чтобы
не потерять прогресс тем же образом второй раз). Автор посмотрел
результат и попросил перекрасить небо и добавить звёзд.

## 1. Небо фиолетовое — должно быть глубоким синим

**Причина:** вихрь round 3 (`docs/tz/web-homepage-fixes-round3/`) был
осознанно сделан в фиолетово-пурпурных тонах (по мотивам референса —
скриншота Elden Ring Nightreign). Автору цвет не понравился на практике.

**Решение (`layout.css`, `nightreign-sky-swirl.svg`):** та же структура
слоёв (виньетка, `conic-gradient` вихря, тёплый отсвет снизу, базовый
радиальный космический градиент в `body::before`; яркая "воронка" в центре
+ процедурная текстура волокон в `body::after`) — меняется только палитра:

- `conic-gradient`: все 9 цветовых остановок переведены из
  фиолетового/маджентового спектра (`rgba(196,130,255,...)`,
  `rgba(219,39,119,...)`, `rgba(147,51,234,...)` и т.п.) в синий —
  от светло-голубого (`rgba(147,197,253,...)`) через акцентный синий сайта
  (`rgba(56,130,246,...)`, тот же тон, что и `--color-accent: #3b82f6`) до
  глубокого тёмно-синего (`rgba(6,12,35,...)`). Так вихрь заодно перестал
  спорить с уже синими элементами интерфейса (кнопки, `--color-accent-soft`
  в бейджах/лейблах) — раньше они были синими на фиолетовом фоне, теперь
  палитра единая.
- Базовый радиальный градиент (глубокий космос): `#2a0a3f/#120620/#05010a`
  (фиолетово-чёрный) → `#12244a/#0a1226/#05070f` (сине-чёрный).
  Виньетка-затемнение по краям (`rgba(5,1,10,...)`) — туда же,
  `rgba(3,7,18,...)`.
- Яркая "воронка"-сердцевина в `body::after`: `rgba(214,188,255,...)`
  (светло-фиолетовый) и `rgba(139,92,246,...)` (violet-500) →
  `rgba(191,219,254,...)` (blue-200) и `rgba(59,130,246,...)` (тот же
  `--color-accent`).
- `nightreign-sky-swirl.svg` (процедурная SVG-текстура волокон,
  `feColorMatrix` тонирует шум `feTurbulence`) — коэффициенты канала
  R/G/B пересчитаны с фиолетового (`0.72 / 0.42 / 1.0`) на синий
  (`0.32 / 0.58 / 0.98`).
- Тёплый отсвет у горизонта (`linear-gradient`, `soft-light`) — оставлен
  (без него исчезает часть глубины/контраста снизу), но убрана розовая
  средняя остановка (`rgba(219,39,119,.1)`, тянула в маджента) — теперь
  просто янтарный оттенок, гаснущий к прозрачности, без розового акцента.

## 2. Мало звёзд

**Причина (`starfield.js`):** `STAR_COUNT_FAR = 160`, `STAR_COUNT_NEAR =
70` — то же значение, что было подобрано в первом раунде
(`docs/tz/web-homepage-fixes/TZ-web-homepage-fixes.md`, п. 4) под
исходный, более плотный фиолетовый фон; на новом синем фоне (менее
"занятом" деталями, чем вихрь round 3) редкие звёзды стали заметнее и
выглядят скудно.

**Решение:** `STAR_COUNT_FAR` → `460`, `STAR_COUNT_NEAR` → `220`
(~680 точек вместо ~230, втрое больше). Обычный 2D-канвас, не WebGL — по
опыту первого раунда даже 200-250 точек были дёшевы, 680 тоже не создают
проблем с производительностью (не измерялось профайлером, но порядок
величины тот же, каждая звезда — один `ctx.arc` вызов).

## Тестирование

Визуальная полировка — проверено вручную через
`uv run uvicorn presentation.web.app:app` и headless Chromium (desktop
1440×900, мобильная эмуляция 390×844). `uv run pytest`/`ruff`/`mypy` —
без изменений в Python-коде, прогнаны как дешёвая проверка регрессий.

## Что осознанно вне рамок

- Точный HEX/RGB подбор под конкретную палитру бренда — цвета взяты по
  ощущению и по совпадению с уже существующим `--color-accent`, не по
  формальному дизайн-гайду (его для вихря никогда не было, см. round 3).
