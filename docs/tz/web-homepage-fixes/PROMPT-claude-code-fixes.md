# Промпт для Claude Code — правки главной страницы

Прочитай `docs/tz/web-homepage-fixes/TZ-web-homepage-fixes.md` — это ТЗ на 7
конкретных доработок уже собранной главной страницы (`presentation/web/`),
найденных при живой проверке в браузере. Каждый пункт в ТЗ разобран по
факту (файл, строка, причина), не только по описанию симптома — используй
эти привязки как отправную точку, не начинай с нуля.

Коротко, что чинится:

1. Земля не помещается в экран — баг в `earth.js` (захардкоженный аспект
   камеры + квадратный рендер-буфер вместо прямоугольного контейнера).
2. Земля должна быть повёрнута стороной, где сейчас ночь, и слегка
   реагировать на движение курсора (на устройствах с мышью — по аналогии с
   уже принятым паттерном в a-kulebyakin.ru).
3. Шрифты не отображаются для кириллицы — у `Space Grotesk` нет кириллицы.
   Меняется на `Unbounded` (заголовки) + добавляется `JetBrains Mono`
   (лейблы/данные), `Manrope` (текст) остаётся. Все три — самохостятся,
   Google Fonts CDN убирается. Полная таблица шрифтов — в ТЗ и в CLAUDE.md.
4. Мало звёзд — статичные 12 градиентов меняются на процедурный canvas-
   генератор (~200-250 звёзд, два слоя плотности).
5. Модальные окна слишком маленькие — увеличить до 60-70% ширины экрана на
   десктопе (с потолком, чтобы не растягивались на широких мониторах).
6. Клик мимо модалки должен её закрывать — сейчас закрывается только
   кнопкой/Esc.
7. Пасхалка-отсылка к атмосфере Elden Ring Nightreign — вихревое
   фиолетово-пурпурное небо. **Копировать ассеты игры нельзя** — только
   настроение/палитра, реализуется как оригинальный CSS-эффект. Триггер —
   пасхалка на самой главной странице (например, серия кликов по логотипу),
   не часть ещё не спроектированных страниц (Итоги недели и т.п. — их
   очередь ещё не пришла, не трогай).

## Процесс

Как и раньше — можно одной веткой на весь этот раунд правок (это не 7
отдельных фич, а один проход полировки одной уже собранной страницы) или
разбить, если так удобнее по факту работы — на твоё усмотрение, здесь
жёсткого требования "одна фича = одна ветка" нет, т.к. правки мелкие и
взаимосвязанные (например, п. 3 и п. 5 оба трогают `modal.css`). Коммиты
всё равно маленькие и по смыслу, не одной кучей. Обязательный рефакторинг-
проход и прогон `ruff`/`mypy`/`pytest` — как обычно.
