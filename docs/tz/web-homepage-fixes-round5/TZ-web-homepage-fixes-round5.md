# TZ-web-homepage-fixes-round5.md — пятый раунд доработки главной страницы

## Контекст

Round 4 (`docs/tz/web-homepage-fixes-round4/`) слит в `main` (#23). После
живой проверки — один пункт: Земля часто показывала просто океан, скучно.

## 1. Земля повёрнута случайной (часто пустой) стороной

**Причина (`earth.js`):** `earth.rotation.y` считался от реального
положения Солнца — `Math.atan2(sunDirection.x, sunDirection.z) + Math.PI`
разворачивал сферу так, чтобы к камере была обращена текущая полуночная
долгота (см. `TZ-web-homepage-fixes.md`, п. 2 — решение было осознанным:
"показывает сторону, где сейчас ночь, видны городские огни"). Проблема
не в самой идее, а в том, что "полночная долгота прямо сейчас" —
астрономически честная, но случайная величина: примерно половину суток она
приходится на Тихий или Индийский океан, где никаких огней нет вообще,
только вода. Раздел "видны городские огни" из round 1 не выполнялся
систематически — только когда полночь совпадала с населённым континентом.

**Решение:** отвязать поворот камеры от реального времени, зафиксировать
его на заранее выбранном угле. Перебраны 12 углов через 30°
(скриншот-сравнение, headless Chromium) — вид на Южную/Юго-Восточную Азию
(Индия, Индокитай, Малайский архипелаг, `EARTH_ROTATION_Y = 150°`) даёт
заметно больше и разнообразнее огней в кадре, чем соседние варианты
(тихоокеанские/индоокеанские ракурсы — вода; дневная Африка на момент
проверки — почти без огней).

День/ночь на самой сфере (терминатор, свечение городов) по-прежнему
считается от настоящего `sunDirection` (см. `getSubsolarDirection`) — это
не менялось и не должно: `NIGHT_LIGHTS_FRAGMENT_SHADER` использует мировую
нормаль поверхности и `sunDirection` независимо от того, как повёрнута
сама Земля, так что вид остаётся физически осмысленным (терминатор
корректно проходит по видимому региону в реальном времени), просто камера
больше не гоняется за полночью по всему земному шару целиком.

Один и тот же угол — и для десктопа, и для мобильного (в отличие от
zoom/сдвига по X из round 4, которые остаются per-breakpoint) — вид
на Азию не завязан на размер экрана, различие только в масштабе/сдвиге.

## Целевые файлы

```
presentation/web/static/js/earth.js — earth.rotation.y: было
  atan2(sunDirection...) + PI (по реальному времени), стало константа
  EARTH_ROTATION_Y = 150° (Южная/Юго-Восточная Азия).
```

## Тестирование

Визуальная полировка — как и в предыдущих раундах, автотестов на
конкретный угол не заводится. Перебор углов и финальная проверка — через
`uv run uvicorn presentation.web.app:app` и headless Chromium (12
скриншотов с шагом 30°, сравнение по видимой площади городских огней).
Проверено, что Земля остаётся статичной (см. round 2/3) — угол теперь
константа, не зависит от времени/анимации.

## Что осознанно вне рамок

- CSS-фолбэк (`.earth-fallback`, путь без WebGL) не получил своей текстуры
  ночных огней — он и раньше использовал только дневную `color.jpg`, это
  не менялось; полноценная поддержка night-текстуры в фолбэке не
  запрашивалась.
- Более сложный подбор угла "максимум огней прямо сейчас" (например,
  анализ пикселей `night.jpg` по долготе) — не нужен: фиксированного
  визуально удачного угла достаточно, точность не требуется.
