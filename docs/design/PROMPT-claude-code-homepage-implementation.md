# Промпт для Claude Code — реализация главной страницы

Работаем в репозитории `nasa-media`. Веб-этап описан в `docs/tz/TZ-web.md` —
прочитай его первым, это основной источник решений и обоснований, здесь
только порядок действий.

## Шаг 1 — импортировать дизайн

Используй MCP `claude_design` (`https://api.anthropic.com/v1/design/mcp`,
авторизация `/design-login`) и импортируй проект:

https://claude.ai/design/p/cba4ea58-066d-4099-98ad-702fa136a2f2?file=Главная+nasa-media.dc.html

Сфокусируйся на файле `Главная nasa-media.dc.html` (весь проект читаем) и
дополнительно прочитай `support.js`, который он импортирует. Реализовать
нужно конкретно вариант **4b** ("Боковая иконочная навигация · Земля
справа") — остальные концепты в проекте оставлены как история выбора, их
трогать не нужно. Это единственный источник точных значений (цвета,
отступы, радиусы, blur) — `TZ-web.md` их не задаёт числами, бери из файла.

## Шаг 2 — реализовать по TZ-web.md

Полное обоснование стека (FastAPI + Jinja2 + vanilla JS + Three.js),
разбивка по файлам, источники данных для карточек ежедневной статистики,
рефакторинг `ApodProvider` и границы (что не входит в этот заход) — всё в
`docs/tz/TZ-web.md`. Ключевое, что не является частью исходного дизайна и
добавлено отдельно:

- **Клик по карточке ежедневной статистики открывает модальное окно** с
  подробной информацией (APOD/астероид/космическая погода/событие Земли) —
  этого не было в дизайне, требование добавлено поверх него. Реализация
  через нативный `<dialog>`, ленивая подгрузка деталей — см. раздел
  «Модалка по клику» в TZ.
- Текстуры Земли уже лежат в репозитории некоммиченными
  (`c7n8gttq5hxc-Earth/Maps/`), но их происхождение/лицензия не
  задокументированы — **прежде чем коммитить их в публичный репозиторий,
  уточни у автора источник**; если неясно — замени на открытые снимки NASA
  Visible Earth/Blue Marble (public domain).

## Процесс

Как и для всех предыдущих фич — отдельная ветка, маленькие коммиты по
смыслу, обязательный рефакторинг-проход после того, как заработало, тесты
до PR (не после). Список тестов — в TZ-web.md, раздел «Тестирование».

Остальные 6 разделов (APOD, EPIC, Астероиды, Погода, События, Итоги
недели) — только заглушки-роуты в этом заходе (см. TZ), не полноценная
вёрстка — не начинай их реализацию сейчас.
