# Промпт для Claude Design — 5 вариантов главной страницы nasa-media

Готовый текст для вставки в Claude Design. Задача на этом заходе — только
главная страница (лендинг), 5 разных концептов. Остальные страницы (APOD,
EPIC, Астероиды, Космическая погода, События Земли, Итоги недели) — следующий
заход, после того как один из вариантов будет выбран/скомбинирован.

---

## Промпт

Спроектируй 5 РАЗНЫХ по композиции концептов главной страницы веб-платформы
`nasa-media` — сайта, дающего доступ к данным NASA (картинка дня, снимки
Земли, астероиды, космическая погода, события на Земле) и сопровождающего
одноимённого Telegram-бота. Нужны и десктопная, и мобильная версия для
КАЖДОГО из 5 концептов — адаптивность закладывается сразу, не отдельным
проходом потом.

### Контекст проекта

`nasa-media` — платформа, объединяющая пять источников данных NASA:

- **APOD** — картинка дня с описанием.
- **EPIC** — снимки Земли (в т.ч. таймлапс-анимации).
- **NeoWs** — околоземные астероиды.
- **DONKI** — космическая погода (вспышки, выбросы плазмы и т.п.).
- **EONET** — заметные природные события на Земле (пожары, штормы и т.п.).

Это не просто галерея картинок — платформа про "что происходит в космосе и на
Земле прямо сейчас", с ежедневной и еженедельной сводкой. Тон — увлечённый
наукой, но не сухой академический; современный tech-продукт, а не
государственный портал.

### Структура навигации (navbar)

Логотип/название `nasa-media` слева (или по центру в мобильной версии — на
усмотрение варианта), пункты меню:

- Главная
- APOD (Картинка дня)
- EPIC (Снимки Земли)
- Астероиды
- Космическая погода
- События Земли
- Итоги недели

На мобильных — бургер-меню или нижняя навигационная панель, на усмотрение
конкретного концепта (разные варианты могут решать это по-разному, это часть
того, что должно отличаться между 5 концептами).

### Фоновый элемент — вращающаяся Земля

Ключевой визуальный якорь всей страницы. Требования:

- Крупная, доминирующая — занимает **85–90% экрана**, а не маленький шарик,
  подвешенный где-то в углу космоса. Ощущение "находишься рядом с планетой",
  а не "смотришь на неё издалека".
- Плавное, непрерывное, медленное вращение вокруг своей оси — без рывков,
  без остановок.
- Должна работать и на мобильных экранах — если полноценный интерактивный
  3D-рендер (WebGL/сфера с текстурой) слишком тяжёл для слабых устройств,
  предусмотреть уже на уровне дизайна лёгкий fallback (например, зацикленное
  видео/последовательность кадров) без потери ощущения "рядом с планетой".
- Контент поверх Земли должен оставаться читаемым — это и есть повод для
  эффекта стекла (см. ниже), а не сплошная плашка, перекрывающая фон целиком.

### Приветствие — ежедневная статистика

Первое, что видит посетитель, — не только логотип и подпись, а живой
акцентный блок с сегодняшними данными платформы. Например (иллюстративно,
конкретный набор цифр можно варьировать между концептами):

- Сколько дней подряд ведётся APOD / какой день по счёту.
- Сегодняшний ближайший астероид (расстояние / размер).
- Статус космической погоды (спокойно / есть вспышка и т.п.).
- Свежее природное событие с Земли (EONET).

Это должно ощущаться как "здесь сегодня происходит что-то конкретное", а не
статичный маркетинговый заголовок.

### Эффект стекла (glassmorphism)

Контентные блоки (карточки статистики, превью источников данных, CTA) —
полупрозрачные, с блюром фона (Земли и звёзд) под собой: `backdrop-blur`,
тонкая светлая обводка (1px, полупрозрачная), мягкое свечение по краю,
лёгкая тень. Ощущение стеклянных панелей, через которые видно вращающуюся
планету, а не сплошные непрозрачные карточки.

### Эстетика — на грани минимализма и максимализма, ближе ко второму

Не пустой воздух и не одна строка текста на экран — многослойная композиция:
крупная типографика вперемешку с плотными блоками данных, несколько
акцентных цветов (не монохром), декоративные детали (частицы/звёзды,
свечения, тонкие орбитальные линии) в дополнение к Земле. При этом не хаос —
у каждого элемента должно быть чёткое место в сетке, никакого нагромождения
без композиционной логики. Ориентир по духу (не по содержанию) —
дэшборд-подобные space-tech интерфейсы, а не строгий корпоративный
минимализм.

### Требования к 5 концептам

Сделай их РАЗНЫМИ по существу, а не 5 вариациями одной раскладки:

1. Разное позиционирование Земли (по центру, смещена вправо/влево, "снизу
   вверх" как горизонт планеты и т.п.).
2. Разное расположение блока ежедневной статистики (единый широкий блок vs.
   несколько отдельных стеклянных карточек, разбросанных по композиции).
3. Разный акцент навигации (классический navbar сверху vs. боковая
   навигация vs. что-то более нестандартное).
4. Разная плотность контента на первом экране (сколько источников данных
   анонсируется сразу превью-карточками, а не только в меню).
5. Разная цветовая температура (например: глубокий космос + янтарный акцент
   vs. более голубая/бирюзовая палитра данных vs. более тёплый вариант) —
   в рамках общей space-tech темы, не блеклый корпоративный стиль.

### Формат результата

Для каждого из 5 концептов — десктопная версия и мобильная версия. После
выбора и, возможно, комбинирования элементов из разных концептов — следующим
шагом будут спроектированы страницы отдельных источников данных (APOD, EPIC,
Астероиды, Космическая погода, События Земли, Итоги недели) в том же стиле.

## Что осознанно не включено в этот заход

- Дизайн внутренних страниц источников данных — отдельный, следующий проход
  после выбора концепта главной страницы.
- Конкретная техническая реализация вращающейся Земли (Three.js/видео/CSS) —
  решается на этапе вёрстки выбранного концепта, не на этапе дизайна.
- Конкретные цифры ежедневной статистики — реальные данные придут из
  бэкенда (`application`/`domain` слои, уже частично реализованы для
  дайджеста и итогов недели), в дизайне это плейсхолдеры.
